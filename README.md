# ASP.NET Core & Angular Clean Starter

A lightweight, modern, and production-ready full-stack template combining **ASP.NET Core** and **Angular**.

This repository serves as a clean, hassle-free alternative to default Visual Studio SPA templates. It leverages **Angular Signals** for seamless reactive state management out-of-the-box, avoiding common change-detection and Zone.js pitfalls.

## 🚀 Features

- **Backend**: ASP.NET Core Web API (.NET 10)
- **Frontend**: Modern Angular with Signals for optimal reactivity and clean data-binding
- **Developer Experience**: Built-in HTTP proxy support for seamless local development in Visual Studio or VS Code
- **Zero Bloat**: No complex boilerplate or unnecessary architectural abstractions—just a solid, transparent foundation for your next project
